# 🚀 Apocalypse Flyleague (APOCFLY)

## 🌟 项目定位

**Apocalypse Flyleague (APOCFLY)** 是一个围绕模拟飞行联飞环境的技术工具集，由几位爱好者共同维护。  
项目早期以完全开源的方式运营，旨在帮助更多玩家搭建自己的小型联飞平台。  
但过去一段时间中，因许可证被反复无视、代码被抹除署名后用于不当用途，我们被迫重新思考项目的开放边界。

## ⚖️ 为什么调整？

我们依然相信开放与共享的价值，但同时也认识到：**没有边界的善意，容易被滥用。**

过去一段时间，我们多次发现：
- 代码中的版权声明被直接删除；
- 项目被重新打包，以“原创”身份分发；
- 部分使用者未履行 MIT 协议最基本的署名义务。

这些行为违背了开源的基本伦理，也让维护者感到疲惫与失望。

因此，我们选择**缩小开放范围，以保护项目本身的可持续性**。


## 📦 核心闭源

自 **2026 年 6 月 28 日** 起，APOCFLY 的资源发布策略调整为：

### 🔒 闭源部分

| 内容 | 说明 |
| :--- | :--- |
| FSD-Universe 完整核心引擎及新版本代码 | 不再以任何开源许可证发布，不再公开源代码 |
| 管理运维脚本、自动化工具 | 转为内部使用，不再对外提供 |
| 高级功能模块（语音桥接、Web 管理面板等） | 不再公开发布或维护 |

这部分内容目前**仅限维护团队内部技术交流**，暂不对外提供下载或授权。


### 📄 公开部分

我们保留了以下资源对外公开：

#### ① Lite 版本（公开免费，AGPLv3）

这是一个**功能精简的公开版本**，仅包含基础 FSD 联飞核心能力：

| 项目 | 说明 |
| :--- | :--- |
| 包含内容 | 基础 FSD 服务端（无高级功能） |
| 适用场景 | 与少数好友进行简单联飞 |
| **许可证** | **GNU Affero General Public License v3** |
| 技术支持 | 不提供任何形式的技术支持或维护承诺 |

> Lite 版本是我们对社区仍保留的一份诚意，供有基础需求的飞友免费使用。但它**不包含**任何高级功能，也不承诺持续更新与维护。

#### ② 公开文档（CC BY-NC-SA 4.0）

| 内容 | 说明 |
| :--- | :--- |
| 管制员/机组 SOP、培训文档 | 可供学习参考，不可商用 |
| 软件使用教程等 | 欢迎社区借鉴，需保留署名 |
| 配置思路与逻辑说明 | 帮助有基础者自行摸索 |

## 💬 最后的话

我们从不反对别人搭建自己的联飞平台，也不介意技术被分享。

但**署名是最低限度的尊重**——如果连这一点都无法被保障，那么开放的意义也就荡然无存。

我们依然相信善意，但也必须用规则保护这份善意。感谢真正理解并尊重开源的每一位朋友。

闭源的决定并非我们乐见，但为了项目的长远健康发展，这是不得不走的一步。

我们仍然愿意对社区释放善意，但不再无条件地将全部心血拱手相让。

**保持热爱，继续飞行！ 🛫✨**
